# Portfolio Assets Directory

This folder holds all images and scrapbook assets for Mokshitha Gali's portfolio.

## Structure:
- `profile/`:
  - `placeholder-portrait.svg`: Stylized editorial portrait placeholder.
  - To use your own photo: simply place your portrait image as `mokshitha.jpg` or `profile.png` inside this `profile/` directory!
- `stickers/`:
  - `earphones.svg`: Apple-style white wired earphones
  - `laptop.svg`: Realistic silver laptop
  - `code-card.svg`: Scrapbook code snippet journal card
  - `paperclip.svg`: Metallic paperclip
  - `coffee.svg`: Ceramic coffee cup with latte art
  - `vintage-camera.svg`: Rangefinder vintage camera
  - `sparkle.svg`: Editorial sparkle / star
  - `cherry.svg`: Realistic cherry pair
- `projects/`:
  - `mana.svg`: Mana Community Platform mockup
  - `mindbridge.svg`: MindBridge wellness platform mockup
  - `trackhire.svg`: TrackHire career tracking dashboard mockup
